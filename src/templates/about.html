Problématique, données, méthodologie, API et équipe.

Problématique

Un NIDS (Network Intrusion Detection System) doit signaler les flux malveillants au milieu d'un trafic légitime très majoritaire. Deux questions : ce flux est-il une attaque ? (classification binaire, priorité au rappel) et de quel type ? (10 catégories). Contrainte d'ingénierie : les features doivent être calculables depuis une capture brute, sinon le modèle est inutilisable en production.

Jeu de données

Source
UNSW-NB15 (UNSW Canberra, Moustafa & Slay 2015) — site officiel
Volume brut
2 540 047 flux, 49 colonnes (4 fichiers CSV, ~586 Mo)
Génération
Outil IXIA PerfectStorm, 100 Go de PCAP, Argus + Bro-IDS + 12 features additionnelles
Cibles
label (0/1) et attack_cat (Normal + Fuzzers, Analysis, Backdoor, DoS, Exploits, Generic, Reconnaissance, Shellcode, Worms)
Échantillon
Stratifié : 60 000 normaux + jusqu'à 8 000 flux par catégorie (toutes les lignes des classes rares) → 106 691 lignes, 91 289 après nettoyage
Features modèle
39 (36 numériques + proto, state, service) ; identifiants IP/ports/horodatages et numéros de séquence exclus

Méthodologie

  1. Échantillonnage stratifié reproductible (random_state=42) puis nettoyage (ports hexadécimaux, valeurs vides, doublons, codage erroné).
  2. EDA + 6 familles de tests statistiques avec correction de Benjamini-Hochberg.
  3. Split stratifié 80/20 ; pipeline ajusté sur le train seulement : features dérivées, imputation médiane, log1p data-driven (asymétrie > 2), filtre de corrélation (|r| > 0,95), Z-score, One-Hot (modalités rares regroupées, inconnues tolérées).
  4. 15 modèles supervisés, GridSearchCV / RandomizedSearchCV, StratifiedKFold(5), scoring F1 / F1-macro ; sélection sur la CV.
  5. Évaluation test : accuracy, précision, rappel, F1, ROC-AUC, PR-AUC, MCC, FPR, matrices de confusion ; Friedman, Nemenyi, Wilcoxon, McNemar.
  6. Explicabilité : 5 méthodes d'importance, SHAP local, ablation par groupe de features.
  7. Non supervisé : K-Means, PAM, CLARA, AGNES, DIANA, DBSCAN, GMM ; anomalies (Isolation Forest, LOF, GMM, distance K-Means) ; règles Apriori.
  8. Extracteur PCAP → 47 features, validé sur le CSV officiel et sur des captures étiquetées.
