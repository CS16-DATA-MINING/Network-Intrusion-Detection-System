# Agent instructions

## Project identity
- Data-mining mini-project (2026/2027): network intrusion detection on **UNSW-NB15**, hybrid track
  (supervised classification + clustering/anomaly detection + association rules) with a Flask web app.
- Targets: `label` (0 normal / 1 attack) and `attack_cat` (Normal + 9 families, `Backdoors` normalised to `Backdoor`).
- `README.md` is the human guide; this file holds invariants for agents. Anonymity: only student codes (team: CS16 lead, CS10, CS26, CS27, RSD07), never real names.

## Single source of truth
- `src/features.py` defines `RAW_COLUMNS` (49), `FEATURES` (39 = 36 numeric + proto/state/service), groups, `ID_COLUMNS`,
  `EXCLUDED_NOISE` (stcpb, dtcpb), `TTL_FEATURES`; `src/config.py` re-exports them and holds all paths.
  Training and PCAP inference both use `FEATURES`. Never add a model feature that `src/pcap` cannot produce.
- Identifiers (srcip, sport, dstip, dsport, stime, ltime) are display-only, never model inputs.

## Layout
- `data/raw/` original CSVs (read-only, git-ignored) · `data/interim/` raw sample + cleaned set · `data/processed/` train/test + split metadata · `data/pcaps/` demo captures + per-flow ground truth (versioned).
- `models/binaire/` and `models/multiclasse/`: deployed `pipeline.joblib` + `metadata.json` (best on CV, full profile).
  `models/all/`: every compared model `{task}_{profile}_{key}.joblib`, `registry.json`, `unsupervised.joblib`, `linkages.joblib`.
- `reports/metrics/` (CSV tables, `curves.json`, `analysis.json`, `unsupervised.json`, `learning_curves.json`, `train_log.txt`), `reports/figures/eda/` (notebooks 01–02) and `reports/figures/evaluation/`.
- Notebooks: `01_eda_and_cleaning`, `02_preprocessing_encoding`, `03_model_training_evaluation` (names imposed by the course), `04_clustering`, `05_regles_association`, `06_explicabilite`, `07_extraction_pcap`.

## Workflow (run from repo root)
1. `python -m src.prepare_data` — stratified sample (60k normal + ≤8k per attack class, `random_state=42`), cleaning, 80/20 split stratified on `attack_cat`.
2. **Training happens in notebook 03** (`src/train.py`: `start` → `train_task` per (task, profile) → `deploy`); `python scripts/train.py` runs the same code. Resumable (skips finished tasks). `NIDS_JOBS` controls parallelism (default 2: the dev machine has 8 GB RAM and was OOM-killed at higher values). Search budgets are deliberately reduced (see `src/models.py`).
3. Notebooks 04–07 (`src.run_unsupervised`, `src.run_analysis` need trained models).
4. `python scripts/update_readme_results.py`, `python scripts/build_report.py`, `python app.py`, `python -m pytest`.

## Artifact contract
- Model files are full sklearn `Pipeline(prep -> clf)`; multiclass labels are integer indices into `registry["class_names"]` (= `ATTACK_CATEGORIES` order).
- `registry["best"][profile][task]` is chosen on the **CV score**, never on test. `src.models.predict_flows` uses the deployed pipelines by default.
- Preprocessing is fitted on train only (inside the pipeline, so re-fitted per CV fold). Never fit on test, never re-split.

## PCAP extractor (`src/pcap/`)
- Reimplements the thesis framework (Argus + Bro-IDS + Alg. 3.2–3.9). Output: exactly the 47 non-target `RAW_COLUMNS` in official order.
- Validated formulas (keep them): `sload=(sbytes-sbytes/spkts)*8/dur`, `smeansz=round(sbytes/spkts)`, `tcprtt=synack+ackdat`, `ct_state_ttl` rules (Alg. 3.3), `is_sm_ips_ports`. `ct_*` are approximate (block-of-100 default, sliding option).
- `generator.py` writes demo PCAPs + per-flow ground truth to `data/pcaps/` (versioned, small).

## Data & git hygiene
- `data/raw/`, `data/interim/`, `data/processed/` are git-ignored; never stage dataset files. Legacy notebooks were `git mv`-ed to the new names (history kept); two leftovers remain in `notebooks/archive/`.
- `DM_PROJECT/`, `Firewall-Traffic-Analyzer/` and the PDFs at the root are reference material, git-ignored.
- Report: `docs/Rapport_MiniProject.pdf` is generated from artifacts by `scripts/build_report.py` (Edge/Chrome headless).

## Editing and validation
- Notebooks are generated by `notebooks/build_notebooks.py`: edit the builder, not the .ipynb JSON. Execute without `MPLBACKEND=Agg` so figures are embedded.
- After changing evaluation code, re-run training/analysis; never report stale metrics. Do not claim the full workflow passed unless it was run end to end.
